Учебный 3D-проект на Unity: лабиринт от первого лица. Нужно собрать 3 ключа и выбраться через дверь до истечения таймера.

Управление
WASD движение
Мышь обзор
E открыть дверь
Alt + F4 Выход

Технологии
Unity 6 LTS (6000.3.26f1)
C#
Universal Render Pipeline (URP)

Реализовано
FPS-контроллер на Character Controller
Сбор ключей (триггеры + события через GameManager)
Дверь с условием открытия
Таймер + Game Over
UI (TextMeshPro): счётчик ключей и таймер
